# Τετράδιο Κουζίνας

Web app για μάγειρες: οι συνταγές σου οργανωμένες ανά εστιατόριο. Δουλεύει στο κινητό σαν κανονική εφαρμογή.

- Λογαριασμός με email και κωδικό. Κάθε χρήστης βλέπει μόνο τις δικές του συνταγές.
- Εστιατόρια με πόλη, χρονιές και θέση.
- Συνταγές με υλικά, βήματα, απόδοση, χρόνους, σημειώσεις σεφ και τα 14 αλλεργιογόνα.
- Αυτόματος υπολογισμός ποσοτήτων για άλλο αριθμό μερίδων.
- Φωτογραφία σε κάθε πιάτο (ιδιωτική, μόνο για τον χρήστη).
- Ανέβασμα έτοιμων συνταγών από φωτογραφία, PDF, Word ή κείμενο, με αυτόματη μετατροπή σε συνταγή.
- Αντίγραφο ασφαλείας (λήψη) και εισαγωγή αντιγράφου.

Είναι απλά στατικά αρχεία (HTML/CSS/JS). Τα δεδομένα αποθηκεύονται στο Supabase.

## Ρύθμιση (μία φορά)

### 1. Supabase: πίνακες

Supabase → **SQL Editor** → **New query** → επικόλλησε όλο το [`supabase/schema.sql`](supabase/schema.sql) → **Run**.

Φτιάχνει τους πίνακες, τον χώρο για τις φωτογραφίες και τους κανόνες ασφαλείας. Μπορείς να το τρέξεις ξανά όποτε προστεθεί κάτι καινούριο: δεν σβήνει τίποτα.

### 2. Supabase: διευθύνσεις σύνδεσης

Supabase → **Authentication** → **URL Configuration**:

- **Site URL:** `https://mydezine.github.io/TETRADIO-KOUZINAS/`
- **Redirect URLs:** πρόσθεσε το ίδιο.

Χρειάζεται για τα email επιβεβαίωσης και αλλαγής κωδικού.

### 3. Στοιχεία σύνδεσης στο `config.js`

Supabase → **Project Settings** → **API**. Αντέγραψε το **Project URL** και το **anon public** (ή **publishable**) κλειδί στο [`config.js`](config.js).

Το anon κλειδί είναι φτιαγμένο για να μπαίνει σε ιστοσελίδες. Την ασφάλεια την κάνουν οι κανόνες του βήματος 1. **Ποτέ μη βάλεις το `service_role` / `secret` κλειδί.**

### 4. GitHub Pages

GitHub → repository → **Settings** → **Pages** → Source: **Deploy from a branch** → Branch: **main**, φάκελος **/ (root)** → **Save**.

Σε δωρεάν λογαριασμό GitHub, το Pages δουλεύει μόνο αν το repository είναι **public** (Settings → General → Danger Zone → Change visibility). Ο κώδικας δεν περιέχει κανένα μυστικό, οπότε αυτό είναι ασφαλές.

Μετά από 1–2 λεπτά η εφαρμογή ανοίγει στο `https://mydezine.github.io/TETRADIO-KOUZINAS/`.

### 5. Αυτόματη ανάγνωση συνταγών (προαιρετικό)

Για να μετατρέπονται αυτόματα φωτογραφίες, PDF και Word σε συνταγές, η εφαρμογή χρησιμοποιεί το Claude. Χωρίς αυτό το βήμα, το «Ανέβασμα» δουλεύει μόνο με επικολλημένο κείμενο, και με πιο απλή ανάγνωση.

1. Φτιάξε κλειδί στο [console.anthropic.com](https://console.anthropic.com) → **API Keys** → **Create Key** και βάλε λίγη πίστωση (Billing). Κοστίζει περίπου 5–10 λεπτά του ευρώ ανά συνταγή.
2. Supabase → **Edge Functions** → **Secrets** → πρόσθεσε `ANTHROPIC_API_KEY` με τιμή το κλειδί.
3. Supabase → **Edge Functions** → **Deploy a new function** → **Via Editor**. Όνομα: `import-recipe`. Σβήσε ό,τι έχει και επικόλλησε όλο το [`supabase/functions/import-recipe/index.ts`](supabase/functions/import-recipe/index.ts) → **Deploy**.
4. Στη σελίδα της function → **Details** (ή Settings) → κλείσε το **Verify JWT / Enforce JWT verification** → **Save**. Η function ελέγχει μόνη της ότι ο χρήστης είναι συνδεδεμένος.

## Εγκατάσταση στο κινητό

- **iPhone (Safari):** Κοινή χρήση → **Προσθήκη στην οθόνη αφετηρίας**.
- **Android (Chrome):** ⋮ → **Εγκατάσταση εφαρμογής** (ή «Προσθήκη στην αρχική οθόνη»).

## Μεταφορά από την έκδοση του claude.ai

Στην παλιά έκδοση πάτα **Αντίγραφο ασφαλείας**. Οι φωτογραφίες δεν περιλαμβάνονται στο αντίγραφο. Στη νέα: **Μενού → Εισαγωγή αντιγράφου…** και διάλεξε το αρχείο.

## Αρχεία

| Αρχείο | Τι κάνει |
| --- | --- |
| `index.html` | Η σελίδα της εφαρμογής |
| `app.js` | Όλη η λογική: σύνδεση, συνταγές, υπολογισμοί |
| `styles.css` | Εμφάνιση (ανοιχτό και σκούρο θέμα) |
| `config.js` | Στοιχεία Supabase |
| `manifest.webmanifest`, `sw.js`, `icons/` | Εγκατάσταση στο κινητό και λειτουργία χωρίς ίντερνετ |
| `supabase/schema.sql` | Πίνακες, χώρος φωτογραφιών και κανόνες ασφαλείας |
| `supabase/functions/import-recipe/index.ts` | Μετατροπή φωτογραφίας/PDF/κειμένου σε συνταγή με το Claude |
